# Foku

Foku is a native macOS menu bar study companion with a pixel-art pet, deterministic rule-based behavior, local-first study tracking, XP, Bond, Momentum, missions, and privacy-conscious focus validation.

This repository is the source of truth for the app, the architecture, and the IB MYP 5 Personal Project process.

## Current stage

**July 2026:** early development before formal IB documentation starts in September 2026.

The current goal is not to write the final report yet. The goal is to build the real app early and keep short notes that can become evidence later.

## Build priorities

1. Native macOS menu bar app.
2. Popover with timer and Foku pet placeholder.
3. Focus session tracking.
4. Local storage.
5. XP and levels.
6. Bond and Momentum.
7. Deterministic state machine and rule engine.
8. Pixel-art animations.
9. Dashboard.
10. Optional Focus Guard.

## Rules for development

- Keep the app local-first and offline-capable.
- Do not add server dependency in the first version.
- Do not add paid systems during the IB stage.
- Do not let AI control XP, Bond, Momentum, rewards, or pet state.
- Use AI only for help with planning, coding, debugging, and optional dialogue text.
- The Xcode project, GitHub repository, and docs folder are the source of truth.
