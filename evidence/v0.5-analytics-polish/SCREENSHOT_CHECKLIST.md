1. Menu bar popover main timer
   - Shows pet, timer controls, subject/intention area, daily progress.

2. Session self-check and reflection
   - Shows self-rating options and reflection note field.

3. Latest session summary
   - Shows completed session result, XP/rules, Bond/Momentum impact.

4. Session insights card
   - Shows Best part, Subject, Reflection, Next improvement.

5. Dashboard overview
   - Shows Today at a glance and Dashboard structure.
