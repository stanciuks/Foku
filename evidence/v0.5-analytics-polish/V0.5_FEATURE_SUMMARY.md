# Foku v0.5 Feature Summary

## Core prototype

Foku is a native macOS menu bar focus app with:

- a focus timer,
- pause/resume/complete/abandon flow,
- custom session durations,
- subject tags,
- study intention,
- self-check rating,
- optional reflection note,
- local progress persistence,
- XP, Level, Bond, Momentum, streaks,
- deterministic pet mood,
- daily stats and missions,
- dashboard analytics,
- achievements,
- privacy/local data controls.

## v0.5 analytics polish

v0.5 adds or stabilizes:

- local study summary export,
- Markdown copy/save workflow,
- open saved export in Finder,
- collapsible export preview,
- deterministic session insights,
- focus quality trend analytics,
- stronger deterministic engine tests.

## Deterministic tested engines

The full test suite covers:

1. DeterministicRuleEngine
2. SubjectTagEngine
3. AchievementEngine
4. FeatureAccessEngine
5. StudySummaryExportEngine
6. SessionInsightEngine
7. FocusQualityTrendEngine
8. App build check

## Monetization-ready but not monetized

The app includes a Feature Access preview to think about future product packaging.

There are no payments, subscriptions, ads, account systems, or App Store logic in this IB-stage prototype.
