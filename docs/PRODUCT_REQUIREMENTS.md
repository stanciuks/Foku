# Foku Product Requirements

## Must have for first working version

- App appears in macOS menu bar.
- Clicking menu bar item opens a popover.
- User can start a focus session.
- User can pause/resume a session.
- User can complete or abandon a session.
- App shows remaining time.
- App shows simple Foku mood text.

## Must have for strong IB prototype

- Local session history.
- XP and level system.
- Bond system.
- Momentum system.
- Deterministic rule engine.
- State machine.
- Privacy explanation.
- Dashboard with basic stats.
- Basic pixel-art pet animation.

## Should have later

- Missions.
- Unlockables.
- Focus Guard.
- Strict Mode.
- Better animation states.
- Exportable study report.

## Future commercial extension

- Website release.
- Signed and notarized app.
- Auto-update system.
- Optional Pro unlock.
- Optional server sync.
- Optional AI summaries.
